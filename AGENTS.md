# Agent notes

Keep these files up to date in the same change as the code:

- [FEATURES.md](FEATURES.md): add or change a row when a feature is added, changed or removed. Name the main source and the test.
- [DECISIONS.md](DECISIONS.md): add a row when a decision is made; change its status when it is reversed.
- [FUTURE_IDEAS.md](FUTURE_IDEAS.md): ideas deferred on purpose. Move an idea out when it is picked up.

Releases follow [RELEASING.md](RELEASING.md).
